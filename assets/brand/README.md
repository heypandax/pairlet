# Pairlet icon

2026-10-03: the owner dropped the "Pocket" label. Every platform icon is back to the text-free chevron + cursor mark that shipped before the 2026-09-10 transition (restored from git, `bafa8a47^`). The iOS launch image keeps its artwork; only its text changed ("Pairlet" and the English tagline). A new logo is being explored separately (Claude Design board "Pairlet Logo").

## Masters and their copies

| Master | What it is | Used for |
|---|---|---|
| `symbol.png` (512 px) | Text-free mark, the master for the desktop icon. Currently byte-identical to `sips -z 512 512 pairlet-icon-1024.png`, i.e. the same artwork as the app-icon master. | `mobile/composeApp/src/desktopMain/resources/app-icon.png` — byte-identical copy, written by the script |
| `symbol-32.png` (32 px) | Separately drawn 32 px miniature of the mark | `site/favicon-32.png` — byte-identical copy, kept by hand |
| `symbol.svg` | 32×32 SVG wrapping `symbol-32.png` as an embedded image | `site/favicon.svg` — byte-identical copy, kept by hand |
| `pairlet-icon-1024.png` (1024 px) | App icon master with its dark background | Resized by the script into the targets below |

`python3 scripts/generate-brand-icons.py` (macOS, `sips` + `iconutil`) converts sizes and containers only; it does not draw artwork:

- from `pairlet-icon-1024.png`: `iosApp/iosApp/Assets.xcassets/AppIcon.appiconset/icon-1024.png` (1024), `harmony/AppScope/resources/base/media/app_icon.png` (1024), `harmony/entry/src/main/resources/base/media/icon.png` (1024), `site/apple-touch-icon.png` (180), the ICNS representations of 64 px and larger in `mobile/composeApp/desktop-icons/cc-pocket.icns`, and the 256 px entry of `mobile/composeApp/desktop-icons/cc-pocket.ico`;
- from `symbol.png`: the desktop `app-icon.png`, copied without resizing.

The ICNS keeps its existing representations below 64 px and the ICO keeps its existing entries below 64 px (original small no-text artwork). Android launcher files are the restored originals and are not regenerated; they keep the adaptive safe-zone inset. Tray drawing is unchanged.

To change the icon, edit the master first, run the script, then copy `symbol-32.png` / `symbol.svg` to `site/favicon-32.png` / `site/favicon.svg` if the miniature changed. Review `git diff --stat` before committing: the script rewrites the ICNS and ICO containers on every run.

Store screenshots, preview videos and site share images are produced by their own pipelines and are not regenerated by this script.
