独立 Claude 登录会共享什么

简短答案

daemon 的独立登录只隔离 Claude 凭据；会话历史、CLAUDE.md、skills、plugins、settings 和 MCP 配置仍与电脑上的普通 Claude 环境共享。

最近核验 2026-07-25·公开链接 · 无需登录

哪些内容会隔离

只有凭据存储归 daemon 独立使用。在 CC Pocket 中登录或退出，只会改变 daemon 的 Claude 凭据，不会替换终端中 Claude 的登录状态。

哪些内容仍然共享

  • 会话历史（projects），因此恢复会话和跨设备接续仍然有效。
  • CLAUDE.md、settings、agents、commands、skills、plugins 和 todos。
  • 保存在 .claude.json 中的 MCP 服务器配置与项目信任信息。
这是“凭据隔离”，不是另建一套 Claude 工作区或多账号会话库。
