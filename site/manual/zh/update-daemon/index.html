更新 daemon

简短答案

执行 cc-pocket-daemon update。如果安装由 Homebrew 或 Scoop 管理，请改用对应包管理器。

最近核验 2026-07-25·公开链接 · 无需登录

选择对应更新方式

  1. 1

    内置安装器

    通过官方 shell 或 PowerShell 安装脚本安装时，使用此命令。

    cc-pocket-daemon update
  2. 2

    macOS 的 Homebrew

    必须使用完整 cask 名；Homebrew 官方仓中存在一个无关的同名 cask。

    brew upgrade --cask heypandax/tap/cc-pocket
  3. 3

    Windows 的 Scoop

    daemon 由 Scoop 安装时使用此命令。

    scoop update cc-pocket-daemon

确认更新结果

执行 cc-pocket-daemon status，再返回 CC Pocket。daemon 重启后，仍有效的设备配对会自动重新连接。
