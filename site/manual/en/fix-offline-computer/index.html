Fix an offline computer

SHORT ANSWER

On the offline computer, run cc-pocket-daemon status. If the daemon is stopped or cannot reach the relay, restore its service or network first. Re-pair only when the app says the pairing is invalid.

Last verified 2026-07-25·Public URL · no sign-in

Check the daemon

  1. 1

    Inspect status

    The status command checks the local daemon process and its relay link.

    cc-pocket-daemon status
  2. 2

    Restore the service or network

    Wake the computer, confirm it has internet access, and let the installed login service restart the daemon.

  3. 3

    Return to CC Pocket

    The app reconnects automatically when the existing pairing is still valid.

Re-pair only when required

If the app explicitly says the pairing is invalid or the device was revoked, run cc-pocket-daemon pair and add the computer again. A normal temporary offline state does not require re-pairing.
