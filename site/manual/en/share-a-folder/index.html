Share one folder with a collaborator

SHORT ANSWER

Open Settings → Shared folders, choose the folder, access level, and expiry, then send the single-use invite to a trusted collaborator. Revoke it from the same screen when access should end.

Last verified 2026-07-25·Public URL · no sign-in

Create the invite

  1. 1

    Open Shared folders

    In Settings, open Shared folders and choose the folder the guest may use.

  2. 2

    Choose access and expiry

    Pick Review, Collaborate, or Autonomous, then set how long the invite remains active.

  3. 3

    Send the invite once

    The invite is single-use and expires quickly. Send it only to the intended collaborator.

Understand the boundary

The guest can open sessions only under the shared folder, but shell commands still run as the owner’s operating-system user. Folder scope is an application boundary, not an operating-system sandbox.

Use sharing only with people you trust. Revoke the share immediately when collaboration ends.
