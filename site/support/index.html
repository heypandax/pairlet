BEFORE YOU SEND发送问题前

Share the symptom, not the secret.描述现象，不要发送秘密。

  • Never send API keys, pairing codes, access tokens, private keys, or full environment files.不要发送 API Key、配对码、访问令牌、私钥或完整环境变量文件。
  • Redact repository names, paths, logs, and screenshots that contain private project data.发送仓库名、路径、日志或截图前，先遮盖私有项目数据。
  • For security vulnerabilities, use a private GitHub security advisory instead of a public issue.安全漏洞请通过 GitHub 私密安全公告提交，不要发布公开 Issue。
