What's new in 1.5.1

New
• Open documents from chat: tap file paths or Write/Edit cards to read Markdown and other workspace files on your phone
• Browse beyond the home folder: switch filesystem roots, including Windows C: and D: drives, in the directory picker
• Per-agent default models: Claude Code, Codex and OpenCode now remember independent defaults
• Full desktop localization: the desktop app now follows your system language in English or Simplified Chinese
• Bridge controls: update allowed projects, enable owner bypass and configure command allowlists

Fixed
• OpenCode sub-agent sessions are hidden; titles, previews and replayed tool calls now match the other backends
• Usage requests, cache hit rate and cost now follow the selected Today, 7d or 30d range
• Duplicate or empty project rows caused by path variants are merged correctly
• Links no longer swallow trailing Markdown or parenthesis text
• Long agent, model and bridge names no longer push important controls off screen
• Fixed a macOS 26 crash when opening the menu-bar popover
