What's new in 1.7.7

New
• ZCode joins Claude, Codex, Kimi, and OpenCode as a session backend
• Choose a default model and reasoning effort for each supported agent
• Feishu bridge sessions now understand their group, sender, and visible-context limits

Improved
• Voice input stays available with an existing draft and while a turn is running, then appends the transcript for review
• Recently completed sessions remain easy to find, and switching through All Projects no longer wedges a reopened chat
• Feishu reviewed and full-auto modes use clearer, request-scoped approval rules

Fixed
• Windows daemon updates and bridge gateway authentication are more reliable
• Malformed connections and concurrent device-limit races no longer disturb healthy sessions
