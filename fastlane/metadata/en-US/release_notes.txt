What's new in 1.5.2

New
• Approval inbox: pending actions now appear from the daemon even when a push notification is delayed or missed
• Project and session lists show a compact pending-approval button only when something needs your attention
• Feishu Bridge now asks once per outsider request; an approval completes that request without becoming a standing permission
• Built-in Help Center and public smart support make setup, pairing, agents, permissions and troubleshooting easier to discover
• Agent-specific project skills and dynamic capability controls now reflect what each connected backend actually supports

Fixed
• Missed approval pushes no longer leave requests invisible; reopening the app reconstructs the daemon's current queue
• Idle Feishu conversations release their concurrency slot, and open failures now report the precise cause
• Sensitive data remains blocked from bridge replies even after a request receives full execution approval
• Windows closes to the tray reliably, while project lists filter agent-only folders more accurately
• Help and support links preserve context and remain stable during slower answers
