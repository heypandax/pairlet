What's new in 1.7.6

New
• Codex sessions now accept image attachments — send error screenshots or design mocks to Codex just like Claude

Redesigned
• Settings groups its five categories into one clear container, separated from the utility destinations
• Bridge cards split identity, facts, and actions into zones; action buttons wrap as whole controls instead of squeezing, so labels never break vertically on narrow screens or at 200% text

Improved
• Consecutive tool calls in Chat share one source label instead of repeating it between every card
• A streaming turn no longer pins a redundant Running banner — the composer note and Stop control already say it
• Session lists stop printing an untitled session's first prompt twice; the Bridges screen names the computer it controls

Fixed
• Feishu group sessions failed to start on Windows daemons — clean-room launch arguments now survive the Windows shell
