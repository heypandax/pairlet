What's new in 1.7.0

Added
• Full-auto mode can now expire after a chosen duration, falling back to ask-first instead of staying on forever
• Kimi Code CLI backend (preview): open and drive Kimi sessions from your phone
• New global accent color preference (CC Pocket / Codex)
• Usage dashboard now counts OpenCode session tokens

Improved
• Voice input lands in the composer for confirmation instead of sending immediately
• Faster, more reliable downloads and self-updates in mainland China via a new mirror

Fixed
• Background session announcements no longer hijack the session view you are reading
• Gateway server errors are attributed by evidence instead of suggesting /clear
