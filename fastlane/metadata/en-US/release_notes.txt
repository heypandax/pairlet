What's new in 1.5.3

New
• Opus 5 is now the Opus entry in the model picker, so sessions start on the latest Opus without typing a model id
• A default model saved as plain "opus" moves forward with it, while third-party gateways keep using the alias their own tiers are mapped to

Fixed
• Opus 5 sessions measure context usage against their real window, instead of reporting a percentage several times too high
• On desktop, the pending-approval count in the sidebar header sits level with the controls beside it and is no longer clipped
