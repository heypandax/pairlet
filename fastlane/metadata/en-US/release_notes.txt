What's new in 2.1.4

- The agent's steps now show up the moment the first one starts, with a live line for the current step, so the reply area no longer jumps while work is in progress. Failed and not-returned steps are marked separately in the block title.
- Chat layout refresh: Copy message sits on the sender line, spacing between turns and paragraphs is clearer, and the header and composer use fewer boxes.
- Links in replies: tap to open, long-press for Copy link, Open file and copy path. Markdown links open their real destination.
- Copy a file's path with one tap from the file viewer.
- The Full access confirmation appears only the first time you start such a session.
