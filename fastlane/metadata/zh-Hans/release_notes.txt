本次更新（2.0.0）

• CC Pocket 开始过渡到 Pairlet，商店和设备上暂时显示为 CC Pairlet，并通过一次性提示说明改名。
• 电脑端命令简化为 pairlet，沿用原来的子命令；cc-pocket-daemon 继续可用。
• 更新 pairlet.org 官网与帮助入口，兼容新旧 GitHub 仓库链接。
• 改进 daemon 在后台运行时对独立安装的 OpenCode CLI 的识别。
• 新增使用与诊断数据共享开关，可在设置中复制最近诊断编号，便于反馈问题；电脑端诊断单独设置。
• Windows：ZCode 装在 PATH 之外也能开会话，daemon 会按注册表和 Programs 目录定位；找不到时列出全部探测过的路径。
• Windows：托盘图标右键改为打开与左键相同的浮层，带会话与状态信息，替换掉不跟随缩放的原生菜单。
• Windows：更新提示行与已配对电脑卡片的文字重新垂直居中。
• 桌面端：在会话里右键文件路径不再崩溃。
• 桌面端：运行中列表按会话标题显示、项目名降为次行；「最近」里的项目可通过右键移除。
• 「#5 已修复」这类正文不再被当作标题放大，只有「# 」开头的 Markdown 标题才会。
• Android：网关模型列表过长时可以滚动，末尾的模型也能选到。
• DeepSeek Harness：支持官方 npx-only 安装方式；自定义路径可用 cc-pocket-daemon config --dsh-bin 固定。
• macOS：一键脚本安装的 daemon 重新被识别为托管安装，自动更新恢复生效。
