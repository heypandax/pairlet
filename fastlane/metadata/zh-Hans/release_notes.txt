本次更新（1.5.2）

新功能
• 新增审批收件箱：即使推送延迟或丢失，也能从 daemon 主动同步全部待审批内容
• 项目和会话列表仅在存在待办时显示紧凑的「待审批」悬浮入口
• 飞书 Bridge 改为他人每次请求单独审批；一次同意可跑完整请求，但不会变成长期授权
• 内置帮助中心与公开智能客服，设置、配对、Agent、权限和故障排查更容易找到
• 支持按 Agent 发现项目 Skill，并根据连接后端动态展示真实能力开关

修复与优化
• 审批推送漏达时不再看不到请求；重新打开 App 会从 daemon 恢复当前审批队列
• 飞书空闲会话及时释放并发槽位，打开失败时展示准确原因
• 请求获得完整执行授权后，Bridge 回复仍会阻止敏感信息外泄
• Windows 关闭窗口后稳定留在托盘，项目列表也会更准确地过滤 Agent 专用目录
• 帮助与客服链接会保留上下文，慢速回答期间连接更稳定
