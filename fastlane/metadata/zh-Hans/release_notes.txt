本次更新（1.5.1）

新功能
• 聊天内直达文档：点文件路径或 Write/Edit 卡片，即可在手机上阅读 Markdown 等工作区文件
• 目录选择器支持切换文件系统根，Windows 可直接浏览 C 盘、D 盘
• Claude Code、Codex、OpenCode 可分别保存自己的默认模型
• 桌面端完整支持简体中文，自动跟随系统语言
• Bridge 支持编辑授权项目、本人免审批和命令白名单

修复与优化
• OpenCode 子 agent 会话不再混入列表，标题、预览和历史工具卡与其他后端对齐
• 用量页请求数、缓存命中率和花费会跟随 Today、7d、30d 时间范围
• 合并路径写法不同导致的重复项目行，避免点开只剩 New session
• 链接识别不再吞掉 Markdown 右括号和后续括注
• 长 agent、模型和 bridge 名称不再把重要操作挤出屏幕
• 修复 macOS 26 打开菜单栏弹层时的崩溃
