Pairlet (formerly CC Pocket) is the same existing app, with the same bundle ID and pairing data. Version 2.0.0 changes the product name; it does not require users to install a separate app or pair again. It is a companion for the open-source Pairlet daemon that runs on the user's own computer (https://github.com/heypandax/pairlet). Pairing therefore requires a desktop machine. The new desktop command is pairlet; the legacy cc-pocket-daemon command remains supported.

TO REVIEW WITHOUT A COMPUTER: on the pairing screen, tap "Try Demo - no computer needed". The entire UI (project list, chat, tool approvals, usage dashboard) then runs on built-in sample data - no account, no pairing, no network dependency, no AI calls.

CODING SESSIONS: the app is a remote control for command-line coding tools that the user has separately installed and authenticated on their own computer. The coding tool on that computer communicates with its provider using the user's own credentials. Prompts and session content transported between the paired App and daemon are end-to-end encrypted; our relay only forwards ciphertext. Voice dictation uses Apple's system Speech framework by default; the optional alternative sends audio end-to-end encrypted to the user's own computer for offline transcription by locally installed whisper.cpp.

OPTIONAL HELP: the Help screen can open our website's AI customer support. This is a separate HTTPS service, outside the encrypted coding-session channel. Questions submitted there are processed by the project-operated support server and its configured model provider. App analytics, crash reporting, and push notifications also use separate services, as described in the privacy policy: https://pairlet.org/privacy.html

No Pairlet account or login is required. Coding-session communication with the user's own computer uses standard encryption algorithms only: TLS + Noise/X25519/AES-GCM (ITSAppUsesNonExemptEncryption is false).
