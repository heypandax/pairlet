## 交付与完成口径

统一按 [验收与交付要求](VALIDATION.md) 执行。状态依次记录为：待取证／待实现 → 实现中 → 待验收 → 待发布 → 可关闭；不适用的阶段可跳过，但要说明理由。

- “代码通过”不等于“用户环境修复”；真机、特定安装包、上游版本未验收时明确标为待验收。
- 每个任务更新自己的结果区：根因证据、最终改动、提交、实际测试、未执行项与发布需求。初稿中的步骤不得整体勾为完成。
- #389 若只修复已证实的部分链路，需要清楚列出剩余范围，不能以 ACK 单测替代通知实际送达。
- 初次整理没有关闭／评论／改标签／设置里程碑，也没有启动 Claude Code、生产部署或本机服务更新。后续用户另行要求修复、推送、发布并更新 issue；实际执行结果见发布记录，此历史授权不扩展到其他任务。
