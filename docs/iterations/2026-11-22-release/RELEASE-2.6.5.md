# Pairlet 2.6.5

- 修复 Codex `/compact`：部分 app-server 版本只确认压缩请求、不发出压缩回合时，会话会一直卡在执行中，之后的消息全部排队。现在确认后 15 秒内未开始压缩回合，即按压缩完成处理并继续发送排队消息。
- `/review` 已发出但回合尚未开始时，拒绝 `/compact`，避免压缩失败时清掉正在运行的审查回合状态，导致无法中断。
- 跟随超长 Codex 会话时，文件大小不变、只有修改时间变化不再触发整份重读与历史重发（#417，Windows 上更易出现）。
- Windows 上 `pairlet update` 重新注册后台任务时，保留安装时的 `--port`、`--pair-port`、`--relay` 及各 `--*-bin` 参数，多用户的端口隔离（#415）不再因更新丢失。
- 清理已不再使用的代码块横向滚动条组件。

以上修复均在电脑端生效，建议手机与电脑同时更新。各平台安装包统一版本号；iOS 经 App Store 审核后自动发布，TestFlight 外部测试也需等待 Beta 审核。
