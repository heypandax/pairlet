# Pairlet 2.6.3

- 服务器升级，需要更新新版本。请将手机和电脑上的 Pairlet 同时更新，以继续正常连接。
- 完善官方连接入口迁移，保留已有配对，无需重新扫码。
- 优化 Codex 长会话持续观察，增量处理新增记录，减少重复扫描开销。
- 后台服务安装支持自定义监听端口，并检查端口范围与冲突。
- 代码块按消息宽度自动换行，复制时保留原始内容。
- 改善桌面窗口恢复、缩放及退出全屏后的边界，避免窗口超出可用屏幕。
- 修复 Codex 上下文压缩收到请求确认后过早释放进程的问题，等待压缩真正完成后再结束操作。
- 压缩期间发送的消息排队等待，避免误投递到压缩任务。
- 压缩成功后在实时会话及历史记录中显示完成提示。

安装包继续通过 GitHub Releases 分发，本版不接入 OSS。已有配对保持有效；建议手机与电脑同时升级。iOS 经审核后发布。
