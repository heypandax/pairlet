## 验收清单

- 同文案、同信息密度的 before/after，消息底部无孤立复制行。
- 整条、引用和代码各自一键复制，范围准确，无额外菜单；成功反馈无布局跳动。
- 长文滚动、固定输入区、头部信息展开、执行块展开/收起。
- 失败和无结果分开呈现；实时行运行/最近步骤/结束状态不误导。
- 浅色、320pt 小屏、1.6 倍字体及长内容可读，操作不越界。
- 原型模拟与真实产品能力、浏览器验证与真机验证分别说明。

## 推荐布局与交互契约

- 整条复制放入来源行尾端，取消正文末尾的独立复制行；来源与按钮保持同排对齐。
- 用户保留中性容器，Agent 保留无框正文；消息外留白区分换人和同一回合的续写。
- 引用与代码的复制留在内容内部。整条复制保留消息原文与 Markdown；引用复制纯文本；代码复制代码原文。这三种输出不同，不自动合并。
- 工具块保留完整的工具计数、失败与无结果，使用箭头与整行点击展开；实时行标明最近步骤的结果，与回合运行状态区分。
- 头部保留 Agent、权限、电脑、项目；模型在输入区出现一次，展开会话信息仍可查看完整字段。小屏下信息面板覆盖部分正文并单独滚动，不把正文挤成零高度。
- 运行提示无独立胶囊；输入框和附件/模型/会话/上下文/停止控制共用一个容器，减少分散边框。

| 规格 | 原型值 |
|---|---|
| 手机主稿 | 402 × 874；深色主稿与浅色对应 |
| 正文 | 14sp / 22sp，沿用现有字号级别 |
| 间距 | 水平 16pt；换人 24pt；回合内 12pt；段落 10pt |

深浅色沿用项目设计系统；常规复制图标为 tx2，成功状态用 ok。强调色支持 Codex 青绿与陶土，角色区分不依赖强调色。

## 验证记录

已在浏览器实际查看深浅色前后对比，操作整条复制、引用复制和执行块展开。复制反馈显示在原位；展开后分别显示完成、失败和无结果。模拟剪贴板失败时显示失败提示，代码复制按钮未切换为成功。

首轮验收提出并完成三项局部修订：

1. 整条复制继续保留原始消息的 Markdown，引用复制才转为纯文本，代码复制原文；不得因视觉调整改变输出内容。
2. 来源行复制的 44pt 点击区与正文首行无交集，避免干扰文字选择。
3. 长回复的来源行紧邻所复制正文之前，工具块在这条回复前面，避免空来源行与正文之间夹入工具块。

修订后复查：

- 实际 DOM 测量 10 个 Agent 整条复制入口：常规点击区 44 × 44pt，1.6 字号约 44.8 × 44.8pt，扩展点击区底边与正文首行均相隔约 2pt，无交集。
- 实际查看 320pt × 1.6 字号画板，操作头部信息收起及长回复滚动。失败与无结果在小屏下分行展示，长模型名省略，输入工具行换行后停止按钮仍在右侧。
- 核对长回复的实际顺序为工具块、CODEX 来源行及复制、正文、引用与代码，原有孤立来源行已移除。
- 切换已结束场景，实时行、运行提示和停止按钮消失，失败与无结果仍保留，末尾文案明确没有同步到手机。
- 复制原文/引用/代码三种范围已在画板契约与读屏标签中更正。系统剪贴板中的最终粘贴内容未独立核验，不将生成器自己的测试总结当作本轮真机结论。

浏览器复制反馈不等于真机系统剪贴板验证；后续落地仍需验证实际粘贴结果、iOS/Android 长按选字、读屏和动态字体。整条复制移到顶部后，长回复读到末尾可能需要上滚；这项使用取舍保留给用户评审。

## 实现与复查

实现映射：

| 位置 | 本轮落地 |
|---|---|
| `ui/App.kt`、`ui/chat/ChatChrome.kt` | 来源行整条复制、消息间距、单行头部信息、独立滚动的信息浮层；用户容器与正文选区保留 |
| `ui/Markdown.kt` | 手机段落间距与整条复制的成功/失败反馈；原有链接、引用和代码复制范围保留 |
| `ui/chat/ToolProcessBlock.kt` | 手机 10dp 圆角、完整计数、失败/无结果分开、整行展开、最近步骤说明 |
| `ui/VoiceComposer.kt`、`SessionSheets.kt`、`SessionSwitcher.kt`、`ContextGauge.kt` | 一个输入容器，手机控件去掉静态胶囊，按实测宽度排布；单个停止/发送在换行后靠右 |

整条复制的图标为 16dp、视觉区域 28dp、触控范围 44 × 44dp。触控区从视觉区域向上、向来源标签一侧扩展，不越出文本列，也不覆盖正文首行。列表上下留白改为内容留白，保证首条消息的完整点击区处于列表内。流式回复复制当前收到的全部原文，保留 Markdown；测试剪贴板分别验证整条、引用纯文本与代码原文的精确输出，写入抛出异常时不显示成功。

手机模型、会话切换、上下文使用显式 `flat` 样式，桌面保留默认样式与绘制路径。输入工具行测量实际宽度，优先省略长模型名，不缩字号或触控区；测量用的临时布局不向读屏暴露重复操作节点。常规 402pt 场景可以同时展示附件、`gpt-6-astra`、会话数 9+、上下文约 338k 和停止。320pt / 1.6 倍字号时允许换行，单个停止按钮仍在右侧。

独立截图复查后修正了首条消息触控裁切、底部静态胶囊、单个停止按钮铺满整行、头部换行及圆角偏差。中文回归另发现工具状态标记出现时带来的 4px 位移，已调整标题排版和留白，并通过状态切换回归。

与原型的有意差异：

- 同回合普通内容间距仍为 12dp，带整条复制的来源行之前至少 16dp，为向上扩展的点击区留出空间；换人保持 24dp。
- 输入控件沿用产品已有的 48dp 触控下限，未缩成原型标注的 44pt。
- 底部控件使用现有按压反馈；长模型名在平台字体较宽时可能省略。
