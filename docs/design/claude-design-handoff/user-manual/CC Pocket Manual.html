Schedule a prompt for later

Short answer

Long-press the Send button instead of tapping it, choose 30m, 1h, 3h, 8h, or Custom time… in the sheet that appears, then tap Schedule for 23:00. The paired computer’s daemon stores the task and runs it at that time, even with your phone asleep — and turning on Repeat daily changes the button to Schedule daily at 23:00.

Applies to CC Pocket 1.4+·Last verified Jul 24, 2026·3 min read·EN · 中文
“Copy for AI” copies this public URL plus a short instruction — no provider involved.

Before you start: you need a paired computer that will be online at the scheduled time, and a session already open in the project the prompt should run in.

Steps

1

Long-press the send button

In the composer, type the prompt exactly as you would send it now. Then press and hold Send for about half a second instead of tapping — the schedule sheet slides up from the bottom. A normal tap still sends immediately, so nothing changes for everyday use.

1 manual.schedule-send.long-press390×844 @2x · crop 390×420 · composer + held Send
1

1 Send held for ~500 ms; the button shows its pressed state and the sheet begins to rise. Callouts are HTML overlays, never baked into the PNG.

2

Choose when it should run

The sheet offers five choices: 30m, 1h, 3h, 8h, and Custom time…. Picking a custom time opens a wheel picker; the line under it names the computer and the timezone the schedule will use — schedules always follow the computer’s clock, not your phone’s. The confirm button reads Schedule for 23:00, or Schedule daily at 23:00 when Repeat daily is on.

234 manual.schedule-send.open-sheet390×844 @2x · crop 390×470 · schedule sheet open
2·3·4

2 The five time choices. 3 Repeat daily toggle, off by default. 4 Target computer and timezone line, above the confirm button.

3

Confirm, then check the task list

Tap Schedule for 23:00. The prompt leaves the composer and appears as a row in Settings › Scheduled tasks, with the time it will run, the target project path, and its current status. Repeating tasks carry a DAILY badge.

5 manual.schedule-send.created390×844 @2x · crop 390×360 · Scheduled tasks list
5

5 The new task row. Settings › Scheduled tasks is the only place schedules are inspected, changed, or removed.

What happens next

The paired computer’s daemon stores the scheduled task and runs it at the time you selected; nothing is queued on the relay. Repeating tasks run daily at the same time. Permission prompts still apply: if the session’s mode asks before commands, the run waits for your approval instead of proceeding.

Settings › Scheduled tasks shows the status of every task and lets you remove one. If a run fails, that row shows the last failure reason — for example that the computer was offline at the scheduled time.

Troubleshooting

Three things that usually explain it
Holding Send does nothing
The composer is empty, or the session is still streaming a turn. Wait for the turn to end, then press and hold Send again.
The task never ran
Open Settings › Scheduled tasks and read the row’s last failure reason — usually that the paired computer was not reachable at the scheduled time. Remove the task and schedule it again once the computer is online.
It ran an hour off
Schedules use the paired computer’s timezone. Check date there; the sheet shows which zone it will use before you confirm.
