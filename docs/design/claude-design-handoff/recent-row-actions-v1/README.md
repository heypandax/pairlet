# Recent Row Actions v1 —— 桌面侧栏「最近」项目行操作簇

状态：原型已由 Claude Design 交付并自检；已按推荐方案 1a 实现在 `desktop/Sidebar.kt` 的 `GroupHeaderBody`，相关桌面 UI 测试通过，并用离屏渲染核对了 260 与 220 两种宽度。尚未同步到本机桌面 App，也未发版。

- 日期：2026-09-28。
- [在线原型：Recent Row Actions v1](https://claude.ai/design/p/eb401868-d618-47f7-b8d4-4641117d566d?file=Recent+Row+Actions+v1.dc.html)（cc-pocket Design System 2.0 项目，生成模型 Fable 5.1 Max）。
- 起因：机主认为最近列表每行的按钮“效果很差”。原来的四个图标有三种尺寸、三种颜色，间距 7px，没有点击区和悬停底色；折叠箭头混在操作里；悬停才出现的图标会让行抖动；「Open now」胶囊比项目名还抢眼；赭色「+」和赭色图钉互相打架。

## 推荐方案 1a（已实现）

- 折叠箭头移到行首的 16px 列，只表示结构，不做成按钮。整行点击仍然切换折叠。
- 行尾是三个等大的 22px 槽位，顺序为置顶、刷新、新会话，间距 2px，距侧栏右缘 6px，圆角 6。
- 槽位始终占位，悬停只改变透明度（进 80ms、出 120ms），行不再重排，「+」不会从指针下移走。
- 图标统一 12px、1.5 描边。静止时用次要文字色，悬停时抬高底色并提亮图标，按下时底色更深。
- 整行只有「+」是赭色，悬停底色是赭色 12% 透明，按下是 20%。
- 已置顶的行在置顶槽里显示实心图钉作为标记。指针移到该槽时换成带斜线的图钉，表示取消置顶。
- 刷新中该槽常显并旋转，旋转期间忽略点击。
- 当前打开的目录不再用胶囊：名字改为主色、中等字重，后面跟一段灰色等宽的小字「open now」。
- 名字和尾随标记空间不够时按宽度比例收缩，标记收缩速度是名字的 4 倍，名字至少保留 60px。
- 三个槽位都有悬停提示。右键菜单与 28px 行高不变。

被否决的方案：1b 只在悬停时显示折叠箭头，折叠状态在静止时看不出来，而且「+」会跳位；1c 悬停时弹出带边框的胶囊，侧栏里没有这种容器，还会盖住长名字的结尾。

## 与原型不同的地方

- **共享文件夹保留置顶和刷新。** 原型假设别人的共享文件夹不能置顶或刷新，但现有功能支持。静止时这两个槽不占位，让「Shared · 所有者 · 剩余时间」有地方显示。悬停时两个槽回来、尾随文字截断，「+」位置不变。
- **共享标签只改桌面这一行。** 这一行改用原型里的小号描边等宽标签；手机端共用的 `SharedPill` 没有动。
- **没有做⌘ 点击折叠全部。** 原型规格里提到了这个新功能，本轮未实现。
- **置顶项目区的「+」没有改。** 侧栏上方置顶项目行里的「+」仍是旧样式，不在本轮范围内。
- **图标用新画的 12 单位矢量。** 这些图标只用于这一行；会话行的图钉图标没有改。

## 颜色映射

原型标注的是 2.0 设计稿色值，实现时映射到现有 `Tok`：次要图标对应 `tx2`，灰色标记对应 `muted`，悬停图标对应 `tx`，槽位悬停底色对应 `hair` 60%，按下对应 `hair`，运行点对应 `ok`。桌面 2.0 目前只有深色稿；浅色主题沿用同一组 `Tok`，未单独出稿。
